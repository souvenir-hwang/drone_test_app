드론 구술시험 퀴즈

드론 1종 구술시험 암기용 퀴즈 앱
경남SK드론교육원

최신 버전 확인 중… 다운로드 링크 불러오는 중…

주요 기능

  • 임의 출제중요도 기반 가중치 추첨, 전체범위/지정범위 선택 가능
  • 전체 출제차례대로(문제 바로 이동 가능) 또는 무작위 순서
  • 전체 문항 보기모든 문항과 답안을 검색하며 열람
  • 실기평가 행동/구호 확인실기평가 순서별 행동과 구호 확인
  • 업데이트 이력앱 내에서 역대 버전 변경 사항 확인

설치 방법

  1. 위 다운로드 버튼을 눌러 APK 파일을 내려받습니다.
  2. 설치 시 "출처를 알 수 없는 앱" 경고가 뜨면 허용을 눌러 계속 진행합니다.
  3. Play Protect가 검사를 진행할 수 있는데, 정상적인 절차이니 그대로 설치를 완료하면 됩니다.
  4. 이후 업데이트는 앱을 열면 자동으로 안내됩니다.
참고 — 이 앱은 Play 스토어에 등록되지 않은 개인 배포 앱이라 설치 중 보안 경고가 뜰 수 있습니다. 요청하는 권한은 인터넷 접속과 APK 설치 두 가지뿐이며, 개인정보에 접근하는 기능은 없습니다.
